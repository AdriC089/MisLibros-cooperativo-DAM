Proyecto para practicar con git/github. 
Pasos:
1. Inicia sesión en tu cuenta de GitHub.
2. Haz un fork del repositorio MisLibros (https://github.com/cuchilusa/MisLibros-cooperativo-DAM) a tu cuenta de GitHub.
3. Desde Visual Studio Code clona el repositorio MisLibros que tienes en tu cuenta de GitHub. Así tendrás una copia en tu ordenador (local).
4. En la terminal, ve a la carpeta Mis-libros con el comando cd Mis-Libros
5. Crea una nueva rama con tu nombre: git checkout -b Fulanito

6. Elige un libro y busca una foto de la portada en Internet. Guarda la imagen en la carpeta images del repositorio local.
7. En Visual Studio Code, en index.html cambiar la línea de debajo de tu nombre para incluir el nuevo libro en la página web.
8. Registra los cambios (commit) en una nueva rama del repositorio.
9. Sincroniza todo con el repositorio remoto de tu cuenta GitHub.(puedes hacerlo por comandos: git push origin Fulanito)
10. Desde GitHub, haz click en el botón Compare & pull request para solicitar la incorporación (merge) de tu contribución al código en la rama principal del repositorio de la profesora.
11. En el título escribe algo como:"Añadí mi carátula de libro (Fulanito)" 
12. Envía el Pull Request al repositorio de la profesora.
